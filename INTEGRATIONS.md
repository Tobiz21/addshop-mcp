# Глубокая работа Addshop MCP с интеграциями

MCP сначала вызывает `addshop_integration_catalog`, затем
`addshop_integration_status`. Любое изменение сначала выполняется с
`apply=false`. Секрет передается ссылкой вида `env:ADDSHOP_SECRET_NAME`.

## Ozon

Контракт: `ozon_client_id`, `ozon_api_key`, `ozon_import_mode`.

MCP умеет проверить форму, определить наличие конфигурации, построить diff и
подготовить импорт. Сам массовый импорт помечен `bulk_import`: универсальный
configure не имеет права запускать его. Перед исполнением нужны экспорт текущего
каталога, оценка числа создаваемых/обновляемых SKU и отдельное подтверждение.
После импорта следует сверить товары, варианты, цены, остатки, изображения и
ошибки сопоставления артикулов. Раздел остатков Ozon доступен для диагностики,
но на исследованном магазине не содержит формы настройки.

## Wildberries

Импорт: `wildberries_token`, `wildberries_import_mode`.
Остатки: `warehouse_id`, `stock_sync_enabled`.
Заказы: `orders_enabled`.

Токен передается только через `ADDSHOP_SECRET_*`. Настройка склада, синхронизации
остатков и получения заказов может применяться через configure после preview.
Массовый импорт заблокирован тем же правилом резервной копии. Перед включением
остатков MCP должен проверить соответствие артикулов, единицы учета, отрицательные
остатки и выбранный склад; после включения — сделать повторное чтение настроек.

## Яндекс Маркет

Контракт: `api_key`, `campaign_id`, `business_id`, `stocks_enabled`,
`prices_enabled`, `orders_enabled`.

Можно независимо управлять выгрузкой остатков, цен и заказами. Безопасная
последовательность: сохранить идентификаторы, включить только один поток,
проверить его состояние, затем включать остальные. API key никогда не читается
обратно: MCP показывает только `configured`/пусто. Получение заказов считается
операционно чувствительной функцией и должно включаться после проверки статусов,
склада и процесса обработки отмен.

## YML

Контракт: `yml_url`, `yml_import_mode`.

MCP проверяет план и URL, но не запускает массовый импорт универсальным методом.
Production-исполнитель должен сначала скачать фид во временный контур, проверить
XML, количество категорий/offers, уникальность id, валюты, картинки, остатки и
объем обновлений. Затем создается backup, prepare-token и только после отдельного
подтверждения отправляется POST. Повтор POST после timeout запрещен: результат
определяется сверкой каталога.

## HTML / JS / CSS

Контракт: `head_html`, `body_html`.

Инструмент может читать и менять вставки как обычную конфигурацию. Перед записью
следует проверять diff на внешние script/iframe, формы, сбор персональных данных,
несуществующие домены и дубли счетчиков. Секреты и персональные данные нельзя
вставлять в код. После изменения нужна проверка публичной страницы и возможность
вернуть предыдущие значения по журналу.

## Доставка и платежи

В карточках способов доставки обнаружены CDEK, Boxberry, Яндекс Доставка и
Деловые линии: расчет цены, токены, пункты/терминалы отправителя и флаги создания
отправлений. Эти поля уже доступны через сущность `delivery_type`; токены
заблокированы универсальным update. Для production нужны отдельные адаптеры:

- `integration_status` без раскрытия токена;
- расчет тарифа как read-only операция;
- prepare отправления с адресом, весом и ценой;
- отдельное подтверждение создания реальной посылки;
- сохранение внешнего идентификатора и защита от дублей;
- отмена только отдельным подтверждаемым инструментом.

Платежные методы конфигурируются через `payment_type`, однако прием денег,
возвраты и изменение платежного статуса нельзя объединять с редактированием
обычных полей: для них нужны отдельные финансовые инструменты и обязательное
подтверждение каждой операции.

## Общие правила исполнения

1. Read → revision → preview → повторный read → POST → verification read.
2. Никаких автоматических повторов POST после сетевой ошибки.
3. Никаких секретов в аргументах, ответах, журналах или чате.
4. Массовые импорты и внешние отправления требуют backup и prepare-token.
5. Изменение контракта Addshop автоматически переводит модуль в read-only.
